# Elemental Command — Steam 스토어 설명 (한국어)

## 짧은 설명 (30단어 이내)

다섯 가지 원소의 힘을 지휘하는 헥스 그리드 전략 게임. 파티를 구성하고, 화·수·초·빛·어둠의 시너지를 마스터하여 적 대형을 무너뜨리세요.

---

## 상세 설명

**Elemental Command**는 한 번의 명령이 전황을 바꾸는 턴제 전술 전략 게임입니다. 화(Fire), 수(Water), 초(Grass), 빛(Light), 어둠(Dark) 중 하나의 속성을 가진 유닛들로 4인 파티를 편성하고, 헥스 그리드 전장에 배치하세요. 포지셔닝과 속성 궁합, 행동 타이밍이 승패를 가릅니다. 규칙은 금방 익힐 수 있지만, 진정한 숙달에는 수십 시간이 필요합니다.

게임의 핵심은 원소 시너지 시스템입니다. 같은 속성이거나 상성이 맞는 유닛을 인접 배치하면 데미지 배율이 상승하고 특수 효과가 발동됩니다. 스테이지를 클리어할수록 새로운 캐릭터가 해금되어 기존 덱 구성을 다시 생각하게 만듭니다. 젬(gem) 기반의 행동 자원 시스템은 수십 시간이 지나도 매 턴을 신선하게 만들어 줍니다.

스테이지 구조는 당신의 시간을 존중합니다. 간결한 부트 화면 이후 바로 스테이지 선택 맵으로 진입하며, 각 전투는 15분 안에 결정적인 순간을 맞도록 설계되어 있습니다. 후반 스테이지에서는 소극적인 플레이를 처벌하고 공격적인 속성 판단을 보상하는 적 편성이 등장합니다. 최고 난이도 퍼펙트 클리어를 노리든, 비주류 파티 조합을 실험하든 — Elemental Command는 매 세션에 전략적 깊이를 선사합니다.

---

## 주요 특징

- **5속성 시스템** — 화·수·초·빛·어둠 유닛은 각각 고유 스탯과 원소 보너스를 보유. 배치 시너지 발동 시 데미지 20% 이상 상승.
- **헥스 그리드 전술 전투** — 4인 파티를 헥스 보드에 배치. 대형과 인접 관계가 개별 유닛 강도만큼 중요.
- **원소 연쇄 콤보** — 강력한 속성 조합을 발견해 전투 흐름을 단숨에 뒤집고 숨겨진 잠재력을 끌어내세요.
- **성장하는 로스터와 스테이지 진행** — 캠페인을 진행하며 새 원소 유닛을 해금. 해금할 때마다 전략적 계산이 달라집니다.
- **집중형 세션 설계** — 모든 스테이지는 10~15분 전투를 기준으로 설계. 언제든 들어와서 명령하고 떠나거나, 완벽 클리어를 위해 남아 계세요.
- **복잡함 없는 전략적 깊이** — 깔끔한 UI와 간결한 턴 구조로 메뉴가 아닌 판단에 집중.
