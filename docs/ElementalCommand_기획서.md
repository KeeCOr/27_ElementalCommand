- 최종 업데이트: 2026-09-23
- 플랫폼: 브라우저, Windows 로컬 런처 보조
- 최신 GDD: `ElementalCommand_GDD.md`
- 변경 기록: `ElementalCommand_업데이트_내역서.md`

## 제품 정의

5속성 지휘관을 편성하고 헥스 보석 경로로 명령을 완성해 적 약점을 파괴하는 세로형 전술 퍼즐 RPG다.

## 핵심 루프와 가설

스테이지 선택 → 지휘관 편성 → 보석 경로 → 명령·약점 결과 → 승패 회고 → 다음 명령·덱 수정 → 재도전으로 이어진다. 행동 전 예상 결과와 행동 후 다음 실험이 같은 흐름에 있으면 상성 규칙 이해와 재도전율이 높아진다는 가설을 검증한다.

## 2026-09-23 결과→덱/명령 개선

전투 기록에 시도한 명령의 요구 보석과 지휘관 속성을 남긴다. 결과 화면은 최고 효율·낭비 명령을 보여주고, 다음에 재현할 명령과 보강할 지휘관 속성을 한 줄씩 제안한다. 결과는 2.5초 뒤 자동 종료되지 않으며 다음 중 하나를 직접 선택한다.

- `Retry`: 현재 파티와 스테이지로 즉시 재도전
- `Edit Party`: 속성 보강 조언을 편성 화면으로 전달
- `Stages`: 스테이지 선택으로 복귀

기존 결과 패널과 버튼 이미지를 재사용했으며 새 이미지 자산은 없다.

## 컴포넌트와 상태

| 구분 | 설계 |
|---|---|
| 데이터 | 명령명, 요구 보석, 지휘관 속성, 약점 기여도 |
| 계산 | `debriefCommands`가 최고 효율·낭비·다음 명령·보강 속성 산출 |
| 결과 UI | 회고 5줄 + Retry/Edit Party/Stages |
| 편성 UI | 이전 전투의 덱 보강 조언 표시 |
| 빈 기록 | 먼저 완성할 명령 1개 선택 안내 |
| 오류·로딩 | 로컬 동기 계산, 별도 네트워크 상태 없음 |
| 긴 텍스트 | 결과 패널 word-wrap과 짧은 속성 조언 사용 |
