제품 정의

5속성 지휘관을 최대 4명 편성하고 5×6 헥스 보드에서 보석 경로를 연결해 기본 공격·스킬·약점 파괴를 실행하는 세로형 전술 퍼즐 RPG다.

핵심 루프

스테이지 선택 → 편성 → 보석 공급 → 명령 선택 → 약점 대응 → 승패 회고 → 다음 명령·덱 수정 → 재도전.

전투 규칙

항목현재 규칙
보드5열×6행 헥스
속성불·물·자연·빛·어둠
편성지휘관 최대 4명, 편성 속성에 따라 보석 출현 가중치 증가
명령요구 보석 순서를 완성하면 스킬, 실패하면 기본 공격
약점카운터 완성 시 약점 파괴와 적 공격 타이머 초기화

결과→다음 덱/명령

전투 기록은 명령명·요구 보석·지휘관 속성·약점 기여도를 저장한다. 결과 화면은 최고 효율, 낭비 명령, 다음에 재현할 명령, 보강할 속성을 보여주고 자동으로 사라지지 않는다.

행동결과
Retry현재 파티와 스테이지로 재도전
Edit Party보강 속성 조언을 편성 화면으로 전달
Stages스테이지 선택으로 복귀

UI 원칙

기존 네이비 패널, 청록·금색 강조, 포트레이트·보석·버튼 이미지를 유지한다. 명령과 조언은 실제 텍스트로 표시하며 새 이미지 없이 기존 결과 패널과 버튼 자산을 재사용한다.

검증

집중 3개 파일·18개, 전체 14개 파일·82개 테스트와 npm run build 통과. Impeccable detect 0건. 약 1.53MB 청크 경고. 실제 승패 완주와 480×854 줄바꿈·버튼 입력은 미검증.
